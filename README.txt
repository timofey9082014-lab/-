ИМПЕРИЯ+ — первая рабочая версия
=================================
Откройте index.html в браузере.

Стартовый баланс: 10 000 монет.
Тап-кнопки для заработка нет.

Работает:
- главный экран;
- карта регионов;
- рынок с покупкой товаров;
- инвентарь;
- банк;
- сохранение баланса и предметов через localStorage;
- мобильная адаптация.

assets/main-ui-reference.png — сгенерированный визуальный референс интерфейса.
